# Linux Setup

Registro de configurações e instalações do ambiente Linux.

## Estrutura

| Arquivo / pasta | Descrição |
|-----------------|-----------|
| `installs.md` | Registro geral de instalações |
| `installs-arch.md` | Pacotes e ferramentas — Arch Linux (CachyOS) |
| `installs-zorin.md` | Pacotes e ferramentas — Zorin OS |

## Como usar

1. Adicione itens no arquivo da distro correspondente (`installs-arch.md` ou `installs-zorin.md`)
2. Após instalar, mantenha o registro atualizado
